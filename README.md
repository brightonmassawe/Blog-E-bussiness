# NetRi Business (NTB) - E-Business Web Project  ## 📌 Overview **NetRi Business [NTB]** is an integrated business solutions web platform specializing in **Finance, Logistics, and Information Technology**. The project is designed to empower organizations with operational excellence, strategic consulting, and sustainable growth through innovative digital solutions.  ## ✨ Features * **Modern UI/UX Design:** Clean, responsive interface featuring professional dark styling, clear typography, and structured navigation. * **Navigation Bar:** Easy-to-use links for **Home**, **Services**, **Contact**, and **Connect**. * **Business Solutions Showcase:** Dedicated sections ("Get Your Choice") highlighting integrated services combining Finance, Accountancy, and cutting-edge Information Technology. * **Client-Centric Approach:** Focuses on digital transformation solutions, financial advisory, and results-driven strategies for modern businesses.  ## 🛠️ Technologies Used * **HTML5** for page structure and semantic layout. * **CSS3** for styling, gradients, and custom themes. * **GitHub Desktop & Git** for version control and repository management. * **Netlify** for live web hosting and deployment.
